# Exports Souk

Exports « vendus-souk » rangés par recherche (un dossier par marque ou recherche), renommés « date + recherche ».
`_correspondance.txt` donne l'ancien nom de chaque fichier. Les exports sans vente sont dans « À identifier (aucune vente) ».

Ce dossier n'est pas publié sur la page stats (hors de `docs/`).
